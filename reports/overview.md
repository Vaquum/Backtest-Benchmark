# Comparison overview

This is a code-evidenced baseline and extensible benchmark, not a product ranking. The complete grid retains every criterion and every unknown. Scope, implementation and evidence remain separate.

## Cohort and exclusions

Ten original products are excluded from the behavioral grid because no inspectable engine implementation was admitted: TradingView, TrendSpider, MetaTrader 5, NinjaTrader, TradeStation, AmiBroker, MultiCharts, Portfolio123, Portfolio Visualizer and StrategyQuant/X. This is an evidence-eligibility result, not a capability or quality judgment. QuantConnect's hosted service and vectorbt PRO are separate from the admitted LEAN/public-source engines. Zipline-reloaded is one frozen lineage, not a result for all Zipline forks. See [exclusion/re-entry register](../catalog/exclusions.json).

Added coverage: bt and QSTrader for portfolio workflows, Qlib for model research, Jesse for crypto research/execution and hftbacktest for specialized depth/latency replay. This is a deliberately bounded cohort, not an exhaustive inventory of every public backtesting project.
